# 本地巡检演示指南

## 启动与检测

在项目根目录运行：

```powershell
& "D:\CONDA\envs\pytorch314\python.exe" -m streamlit run app.py --server.address 127.0.0.1
```

1. 打开 http://127.0.0.1:8501，填写批次名称。
2. 上传道路照片（每批最多 100 张，单图最多 20MB、3000 万像素），或选择「体验示例」。建议先用少量照片体验。
3. 默认使用 n640 最佳权重、显卡、conf=0.25。检测设置里可改权重、设备和阈值；输入尺寸固定 640。
4. 点击「开始批量检测」。每张完成后保存结果，失败或中断的批次可从左侧重新打开并重试未完成图片。

体验示例使用已有验证图片，不是新的评测数据。

## 人工复核

- 在图片列表上方选择「复核队列排序」：可按低置信度优先、候选框多优先或空图抽查；这只调整查看顺序，不会改动预测框和批次数据。
- 左侧图是原始模型预测，右侧图是当前编辑预览。
- 双击表格单元格修改类别和坐标；选中行后用表格工具栏删除误报，再点击「保存复核结果」。
- 补框时在「在图上补充漏检框」区域选择类别，直接在图片上按住鼠标拖出矩形；可以连续绘制多个框，拖拽结束后点击「保存复核结果」。画布会自动把显示尺寸换算回原图坐标。
- 「坐标表单补框（备用）」保留给需要精确输入坐标的情况。
- 全部框删除后保存，表示人工确认此图当前没有目标；请实际检查图片再确认。
- 每次保存增加版本并保留备注、时间、完整框列表。修改或新增的框不使用模型置信度。
- 切换图片或关闭页面前先保存，未提交的编辑不会导出。支持图片拖框和坐标表格编辑。

## 导出与继续工作

点击「生成导出包」后下载 ZIP，内容包括：

| 文件/目录 | 含义 |
|---|---|
| records.json | 批次、权重哈希、原始预测、复核结果和全部修改历史 |
| summary.csv | 每张图的处理/复核状态、版本、各类框数 |
| originals/ | 经 EXIF 方向校正的 PNG 图片，标注坐标基于这些图片 |
| model/ | 原始预测标注图 |
| current/ | 当前已保存标注图，待复核图片仍使用模型预测 |
| reviewed_labels/ | 仅已复核图片的 YOLO 标签，已确认无目标图片对应空文件 |

导出的框数是逐图累计，不是跨图片去重后的病害数量。导出标签不会自动并入训练集，需要进一步质检与划分检查。

原始批次位于 `runs/inspections/<批次编号>/`。重启后从侧栏选择并打开即可继续。批次创建时记录的权重文件应保留，继续检测时会校验权重。

本应用面向本机单用户演示，不包含账号权限、多用户并发事务或生产部署保障。已有模型的验证成绩存在近重复数据风险，见 [数据审计](../reports/split-similarity.md)；演示可用不等于性能已经验收。
