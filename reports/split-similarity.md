# 跨集合图像相似性审计

日期：2026-09-25。数据版本：rdd_v1。本次未修改图片、标签或集合划分。

## 方法与结果

对 train/val/test 共 11,576 张图片计算 63 位 pHash（去掉 DCT 直流项）及 64 位 dHash。两个哈希的汉明距离分别不超过 6 和 8 时，记录为跨集合相似候选。该检查不使用标注或模型预测。

| 集合对 | 候选图片对数 |
|---|---:|
| train / val | 47 |
| train / test | 57 |
| val / test | 19 |
| 总计 | 123 |

涉及 210 张不同图片。候选中 SHA256 完全相同的图片对为 0。图片对数不能解释为独立道路数。

仅生成 train/val 前 20 对候选的可视化，人工抽查前 3 对。Japan_001370 与 Japan_010787、Japan_001370 与 Japan_010987、Japan_007599 与 Japan_010987 均呈现高度相似的道路画面和视角，提示现有图片级划分存在近重复泄漏风险。没有人工查看本次 test 候选图片或测试预测。

## 结论边界

- 123 对是自动候选，并非全部经人工确认。感知哈希也可能漏掉旋转、裁剪或更大视角变化的相似图。
- 字节去重不能保证道路/拍摄序列独立，现有验证指标可能偏乐观；本审计不能量化偏高多少。
- n640、n960、D10 重采样使用同一旧划分，保留为该划分下的历史对照，不称为独立道路泛化结果。
- 已按当前哈希规则从 test 排除 65 张已知相似候选，并完成 1,672 张留出测试；该结果仍不能解释为道路完全独立成绩。

## 后续数据版本

保留 rdd_v1 与旧实验。后续结合候选复核、来源/序列信息建立分组，按组划分新版本；检查组间相似性和类别覆盖后冻结，再重新训练和评估。缺少可靠道路标识时，只能声称按已知近重复组隔离，不能保证所有道路独立。此次未自动重划分或启动重新训练。
